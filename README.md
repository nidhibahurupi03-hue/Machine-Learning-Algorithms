# Machine Learning Algorithms

This repository contains implementations of basic Machine Learning algorithms using Python and Jupyter Notebook.

## Algorithms Included

- Linear Regression
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes

## Dataset

- Insurance Dataset (`insurance.csv`)

## Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Repository Structure

```
Machine-Learning-Algorithms/
│── linear_regression.ipynb
│── logistic_regression.ipynb
│── KNN.ipynb
│── Naive_Bayes.ipynb
│── insurance.csv
│── requirements.txt
│── README.md
```

## How to Run

1. Clone the repository
2. Install the required libraries
3. Open the notebooks in Jupyter Notebook or VS Code

```bash
pip install -r requirements.txt
```
